Markdown 语法全解（含示例与坑）

语法 · 速查 · 8 分钟 · 2026-10-17

本文按"能直接抄"的方式整理常用语法。所有示例左侧是写法，右侧是渲染效果说明。

1. 标题

两种写法：

# 一级标题
## 二级标题
### 三级标题

一级标题
========

二级标题
--------
  • # 有 16 个，对应 h1h6
  • # 与文字之间必须有空格
  • 下划线式（=== / ---）只支持两级，已不推荐

2. 段落与换行

这是第一段。

这是第二段（中间空一行）。
  • 段落之间必须空行
  • 段内换行：行尾加两个空格再回车（很多平台也支持直接回车换行）

3. 强调

*斜体*  _斜体_
**粗体**  __粗体__
***粗斜体***
~~删除线~~
==高亮==（部分平台支持）

常见坑：中文旁边的 * 有时不生效，建议在星号内侧留空格或改用 _。

4. 列表

无序列表

- 第一项
- 第二项
  - 嵌套项（缩进两格）

-、+、* 都可以，但同一列表里保持一致。

有序列表

1. 第一项
2. 第二项
3. 第三项

数字不必连续，解析器会自动编号。

任务列表（GFM）

- [x] 已完成
- [ ] 未完成

5. 引用

> 单层引用
>> 嵌套引用

引用里可以放标题、列表、代码块，属于"块级容器"。

6. 代码

行内代码

使用 `console.log()` 打印。

代码块（围栏式，推荐）

```js
const price = 12;
```
  • 语言标记（js / python / bash…）决定高亮规则
  • 旧式的"四个空格缩进"仍可用，但不带语言标记

7. 链接与图片

行内式

[链接文字](https://example.com "可选标题")
![图片说明](https://example.com/a.png)

参考式（适合链接很多的长文）

[官网][1] 与 [文档][2]

[1]: https://example.com "官网"
[2]: https://example.com/docs

自动链接

<https://example.com>
https://example.com    （GFM 下直接可点）

8. 表格（GFM）

| 平台 | 状态 | 备注 |
| --- | :---: | ---: |
| 公众号 | 稳定 | 全内联 |
| 小黑盒 | 稳定 | 图文 |
  • 第二行的 : 控制对齐（左 / 中 / 右）
  • 表格不支持合并单元格，需要就退回 HTML

9. 分隔线

---
***
___

三个以上即可；注意 --- 紧跟在文字下方会被识别成"二级标题"，前面要空行。

10. 转义

想显示被占用的符号，用反斜杠：

\* 不是斜体
\# 不是标题
\` 不是代码

11. 脚注（部分平台）

这里有一个脚注[^1]。

[^1]: 脚注内容。

12. 数学公式（部分平台）

行内：$E = mc^2$
块级：
$$
\int_0^1 x^2 dx
$$

本站支持 KaTeX 渲染；公众号等平台通常不解析，会原样显示。

13. 常见坑清单

现象 原因 处理
标题没生效 # 后缺空格 补一个空格
列表连成一段 列表前没空行 列表前空一行
代码块里内容被解析 用了行内代码而非围栏 改用三个反引号
表格错位 列数不一致 每行列数对齐
中文强调失效 星号紧贴中文 星号内侧加空格或换 _
图片不显示 相对路径或防盗链 用绝对 URL

14. 写作建议

  1. 标题层级不跳级：h1 → h2 → h3，利于目录与无障碍
  2. 一段一个意思，别写超长段
  3. 列表优先于长句，扫读性更好
  4. 代码块一定标语言，否则没有高亮
  5. 图片写 alt，既是无障碍也是加载失败的兜底文字
  6. 链接用参考式，长文里改动集中在文末

附：嵌套与容器规则

块级元素可以互相嵌套，但有两条硬规则：

  1. 子块要缩进（列表里的代码块通常缩进 4 或 8 个空格）
  2. 块之间要空行（尤其在引用里放列表时）

引用里放列表：

  • 第一项
  • 第二项

附：HTML 混排

Markdown 允许直接嵌 HTML，常用于它表达不了的东西：

<details>
  <summary>点开看更多</summary>
  这里是被折叠的内容。
</details>

注意：公众号会过滤大部分 HTML，混排前先确认平台是否支持。

附：换行到底怎么写

写法 效果 适用
空一行 新段落（有段间距） 最常用
行尾两个空格 + 回车 段内换行 诗歌、地址
行尾反斜杠 + 回车 段内换行（部分平台） 兼容写法
直接回车 视解析器而定 不推荐依赖

附：表格进阶

左对齐 居中 右对齐
a b c
较长内容 中 1,234
  • 列宽由内容自动撑开，无法手动指定
  • 单元格里不能换行（要换行就拆行或用 HTML）
  • 竖线符号要转义：\|
