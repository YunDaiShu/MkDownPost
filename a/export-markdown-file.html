导出 .md 文件：把源码带走

导出 · 3 分钟 · 2026-11-13

最不起眼但最有用的导出：原始 Markdown。

什么时候用

  • 换工具时迁移
  • 交给别人接着写
  • 存进 Git 做版本管理
  • 作为其他导出的"源"

本站的做法

点导出里的"下载 .md"，得到与编辑器内容完全一致的文件，不做任何转换。

文件名规则

mkdownpost.md

多标签时建议先重命名标签，再导出，便于区分。

和别的导出的关系

.md（源）
 ├─ 内联 HTML（粘贴到平台）
 ├─ Word（交付与二次编辑）
 ├─ PDF 与 PNG（归档与分享）
 └─ 平台适配（公众号、小黑盒、TapTap）

注意

  • 导出的是当前标签页内容
  • 图片仍是相对路径，跨机器迁移时要一起带走 assets 目录
  • 草稿同时存在于浏览器本地存储，导出不是备份的唯一手段

小结

.md 是唯一"无损"的格式。长期写作，养成同时留一份 .md 的习惯。
