# 术语表：Markdown 写作常用词

按字母与主题混合排序，方便检索。

## A 到 E

| 术语 | 解释 |
| --- | --- |
| alt | 图片的替代文本，图裂时显示 |
| CommonMark | 把边界情况定死的 Markdown 规范 |
| front matter | 文件开头的元信息区，本站用外部索引替代 |

## F 到 M

| 术语 | 解释 |
| --- | --- |
| GFM | GitHub 方言，含表格、任务列表、删除线 |
| KaTeX | 本地渲染数学公式的库 |
| Markdown | 轻量级标记语言 |
| Mermaid | 用文字画图表的语法 |

## N 到 R

| 术语 | 解释 |
| --- | --- |
| 内联样式 | 写在元素上的样式，公众号唯一认的形式 |
| 令牌 | 可被主题覆盖的 CSS 变量 |

## S 到 Z

| 术语 | 解释 |
| --- | --- |
| 沙箱清洗 | 用白名单过滤 HTML，去掉脚本与危险属性 |
| 围栏 | 用三个反引号或波浪线包裹的代码块写法 |
| 锚点 | 标题自动生成的跳转标识 |
| 版心 | 正文实际排版的宽度 |
| 降级 | 平台不支持时改用等价表达 |

## 小结

术语表的价值不是背，而是**沟通时能对齐**。遇到不确定的词，先查这里。
