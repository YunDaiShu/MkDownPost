# 用 Mermaid 画流程图与时序图

不用打开绘图工具，用文字就能画出流程图——这是 Mermaid 最大的价值。

## 一个最小例子

```markdown
```mermaid
flowchart LR
  A[写作] --> B[预览]
  B --> C[导出]
  C --> D[粘贴到平台]
```
```

上面的语法会渲染成一条从左到右的流程。

## 常用图类型

| 类型 | 关键字 | 适合表达 |
| --- | --- | --- |
| 流程图 | flowchart | 步骤、分支、决策 |
| 时序图 | sequenceDiagram | 多角色交互顺序 |
| 状态图 | stateDiagram | 状态流转 |
| 甘特图 | gantt | 时间排期 |
| 饼图 | pie | 占比 |

## 本站的处理方式

- 图表**默认不渲染**，显示为可点击的占位块
- 点击后才加载绘图库并渲染（避免首屏卡顿）
- 渲染失败时保留源码，可复制

## 各平台支持

| 平台 | 支持 |
| --- | --- |
| 本站预览 | 支持（点击渲染） |
| GitHub | 支持（原生渲染） |
| 公众号 | 不支持 |
| 其他平台 | 基本不支持 |

## 公众号里的替代

1. **截图为图片**（最稳）
2. **改写成列表**：把流程图拆成步骤
3. **用箭头字符**：A → B → C

```markdown
写作 → 预览 → 导出 → 粘贴
```

## 写作建议

- 图只画"讲不清的关系"，能三句话说清就别画图
- 节点文字要短（4 到 6 字）
- 一张图不超过 10 个节点

## 小结

Mermaid 适合"边写边画"，跨平台发布时要准备截图或文字版。
