# 发布前自检清单：二十项逐条打勾

发布前花十分钟，省掉发布后十次修改。

## 内容

- [ ] 标题说清了"讲什么、对谁有用"
- [ ] 开头三行有结论
- [ ] 每 300 到 500 字有小标题
- [ ] 没有 TODO、待补、占位符残留
- [ ] 没有"见上文"这类依赖上下文的表述

## 结构

- [ ] 标题层级不跳级
- [ ] 只出现一个 h1
- [ ] 列表与表格前后有空行
- [ ] 代码块都标了语言

## 链接与图片

- [ ] 图片是绝对地址且能打开
- [ ] 每张图有 alt
- [ ] 外链可点、没有内网地址

## 排版

- [ ] 主题与目标平台匹配
- [ ] 字号与行宽选好
- [ ] 表格不超过 4 列
- [ ] 代码块没有超长行

## 导出

- [ ] 导出 HTML 后在浏览器检查
- [ ] 粘贴到平台后用手机预览
- [ ] 图片、表格、代码块、外链四项重点看

## 小结

清单的意义是**不靠记性**。习惯之后，你会发现这十分钟是整条流程里回报最高的。
