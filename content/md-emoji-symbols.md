# 符号与 emoji：克制、一致、跨平台

符号能让长文透气，但用多了会显廉价。

## 常用符号

| 用途 | 符号 | 备注 |
| --- | --- | --- |
| 勾选 | ☑ 与 ☐ | 全平台可显示 |
| 进度 | ◐ | 半完成 |
| 箭头 | → ⇒ ↗ | 表达流向 |
| 项目符号 | • · ▪ | 替代默认圆点 |
| 分隔 | ｜ / ｜ | 行内分隔用竖线 |

## emoji 的使用原则

1. **一段最多一个**，放在行首
2. **同一篇风格统一**：要么都用，要么都不用
3. **不用来替代标题**：目录里会乱
4. **不用生僻 emoji**：部分设备显示成方块

```markdown
✅ 今天完成：正文初稿
⏳ 明天要做：配图与排版
```

## 跨平台注意

- 公众号对 emoji 支持良好，但**复制粘贴后可能变成图片**（不可搜索）
- 小黑盒、TapTap 显示正常
- 部分老设备可能不显示新 emoji

## 什么时候别用 emoji

- 正式的技术文档
- 需要打印的内容
- 严肃话题（事故复盘、公告）

## 小结

符号是标点，不是装饰。用它标记状态与流向可以，用它表达情绪要慎重。
