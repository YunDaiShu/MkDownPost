# 代码块样式：底色、语言条与复制按钮

代码块出现频率高，样式没做好会很刺眼。

## 本站的做法

| 部分 | 样式 |
| --- | --- |
| 外层 | 圆角加浅底，与正文拉开层次 |
| 顶部条 | 语言名加复制按钮 |
| 代码文本 | 等宽字体、行高 1.6、可横向滚动 |
| 高亮 | 按语言着色，浅底用低饱和配色 |

## 为什么顶部要显示语言名

- 读者一眼知道这是什么代码
- 复制到别处时知道该贴哪
- 导出到公众号时这一条会被去掉，因为平台不执行脚本

## 长代码的处理

```js
// 超过 80 字符会被横向滚动
const value = await api.get('/very/long/path/with/many/segments', { withCredentials: true });
```

建议主动换行：

```js
const value = await api.get(
  '/very/long/path/with/many/segments',
  { withCredentials: true }
);
```

## 导出到各平台

| 平台 | 表现 |
| --- | --- |
| 公众号 | 保留底色与等宽字体，顶部条被去掉 |
| 小黑盒 | 底色可能丢失，建议截图 |
| GitHub | 原生高亮 |
| PDF 与 PNG | 与屏幕一致 |

## 小结

代码块要能被复制、能被阅读、不抢正文风头。三件事做到，样式就合格。
