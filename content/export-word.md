# 导出 Word：交付与二次编辑

.wdoc 格式适合"给对方改"的场景。

## 本站生成的是什么

一个带 Office 命名空间的 HTML 文件，扩展名为 .doc。Word 能直接打开并保留大部分样式。

## 为什么不用真 .docx

- 浏览器端生成 docx 需要引入较大的库
- 交付场景通常"能打开、能改"就够
- HTML 版 .doc 在 Word 里可另存为 docx

## 产物特点

| 项 | 处理 |
| --- | --- |
| 中文字体 | 声明为黑体与微软雅黑 |
| 页面设置 | A4 |
| 图片 | 转成绝对地址，避免 Word 里裂图 |
| 代码块 | 等宽字体加浅底 |
| 锚点按钮 | 移除 |

## 打开后建议

1. 另存为 .docx（体积更小、兼容更好）
2. 检查图片是否显示
3. 检查表格是否错行

## 小结

Word 导出的定位是"可交付"，不是"完美还原"。要精排，导出 HTML 后在专业软件里处理。
