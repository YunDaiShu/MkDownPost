# 这个网站能做什么、不能做什么

新用户最常问的四个问题，一次说清。

## Q1：它只是个 Markdown 编辑器吗？

**是，但不只是。** 它做的是「**写一次，导出到多个平台**」：

```text
写 Markdown → 实时预览 → 选主题 → 导出（HTML / PDF / Word / PNG）→ 粘贴到目标平台
```

普通编辑器只解决"写"，本站多解决两件：

1. **排版**：100 套主题，每套 23 个颜色令牌 + 分组装饰
2. **适配**：9 个平台各自的导出规则（哪些标签会被过滤、表格要不要降级）

## Q2：有没有 AI？会不会上传我的稿子？

**没有任何 AI，也不会上传。**

| 你担心的 | 实际情况 |
|---|---|
| AI 对话 / 润色 / 摘要 | ❌ 完全没有，代码里没有入口 |
| 稿子会被传到服务器吗 | ❌ 没有服务器，草稿只写本机 localStorage |
| 需要注册登录吗 | ❌ 没有账号系统 |
| 断网能用吗 | ✅ 能（依赖库都在本地 vendor/） |
| 换设备会同步吗 | ❌ 不会（这是"无云端"的代价，导出 .md 自行备份） |

## Q3：能一键发布到公众号吗？

**不能，也不打算做。**

公众号个人主体没有公开发布接口。任何"一键发布"工具都靠模拟登录，既不稳定也违反平台规则。

本站只做**排版导出**：把内容转成"粘进去就好看"的 HTML，最后一步由你发布。

## Q4：为什么同样的稿子在别的平台样式会乱？

因为每个平台都会过滤一部分标签。本站适配器就是处理这些差异：

| 平台 | 会被过滤 / 限制 | 本站怎么处理 |
|---|---|---|
| 公众号 | `<style>`、部分外链、锚点 | 全内联样式，剔除锚点 |
| 小黑盒 | 深层标题显示弱 | h4+ 降级为加粗 |
| TapTap | 表格、任务列表不稳定 | 表格转等宽文本，任务项转 ☑/☐ |
| 知乎 | 代码块过宽 | 限宽 + 横向滚动 |

## 能力边界（先说清，免得失望）

**能做**

- Markdown 全流程写作（GFM：表格、任务列表、删除线、自动链接）
- 代码高亮、公式（KaTeX）、图表（Mermaid，点击渲染）
- 100 套主题 + 自定义主色
- 8 种导出（md / 内联 HTML / Word / PDF / PNG / 打印×2 / 平台适配）
- 多标签草稿、编辑历史、可自定义快捷键

**不能做**

- 云端同步、多人协作、账号体系
- AI 生成、自动摘要
- 一键发布到任何平台
- 印刷级精确排版（那要用专业排版软件）
- 可搜索的 PDF（当前为图片型，原因见 README）

## 一句话总结

**它把"写作"与"排版"分开**：你只管写，排版与平台差异交给主题和导出器。所以同一份 .md 换主题、换平台，正文一个字都不用改。
