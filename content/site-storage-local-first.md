# 本地优先：草稿存在哪、什么时候会丢

本站没有服务器，所有草稿都在你自己的浏览器里。

## 存在哪

浏览器的 localStorage，键名前缀统一，按标签页分别存正文与元信息。

## 什么情况下会丢

| 场景 | 会不会丢 |
| --- | --- |
| 刷新页面 | 不会 |
| 关闭浏览器 | 不会 |
| 清理浏览数据 | 会 |
| 换浏览器或设备 | 不会自动同步 |
| 隐私模式 | 关闭窗口后丢失 |
| 磁盘清理工具 | 可能被清掉 |

## 怎么降低风险

1. 重要稿子同时导出 .md
2. 定期把 .md 提交到 Git 仓库
3. 不要把长期项目只留在浏览器里

## 为什么不做云同步

- 需要账号体系与服务端
- 与"不上传内容"的定位冲突
- 增加合规与运维成本

## 小结

本地优先的代价是"自己负责备份"。收益是内容永远不经他人服务器。
