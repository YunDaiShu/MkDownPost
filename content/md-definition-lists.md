# 定义列表与术语表：Markdown 没有，但可以模拟

标准 Markdown 没有定义列表，技术文档却经常需要"术语加解释"。

## 三种模拟写法

### 一、加粗术语加缩进说明

~~~markdown
**令牌**
: 这里放解释（部分解析器支持这个语法）
~~~

### 二、加粗术语加列表

~~~markdown
**令牌**
- 解释：主题里可被覆盖的 CSS 变量
- 例子：主色、边框色、代码底色
~~~

### 三、表格

~~~markdown
| 术语 | 解释 |
| --- | --- |
| 令牌 | 可被覆盖的 CSS 变量 |
| 主题 | 一组令牌的集合 |
~~~

## 三种写法怎么选

| 场景 | 推荐 |
| --- | --- |
| 术语少于 5 个 | 加粗加列表 |
| 术语多、需要扫读 | 表格 |
| 需要长解释 | 小标题加段落 |

## 版面差异

- 表格最紧凑，但列宽不可控
- 列表最灵活，可放多行
- 小标题最清楚，适合每项说一段

## 小结

没有定义列表不等于没法表达。选一种写法并**全篇统一**，比换三种写法更专业。
