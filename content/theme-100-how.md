# 100 套主题是怎么来的

不是手写一百遍，而是八套手调加九十二套生成。

## 结构

| 来源 | 数量 | 说明 |
| --- | --- | --- |
| 手调 | 8 | 微信、小黑盒、TapTap、哔哩哔哩、知乎、小红书、GitHub、VS Code |
| 生成 | 92 | 由种子色加算法派生 |

## 生成器做了什么

1. 取一个种子色（品牌近似色）
2. 用算法算出 23 个令牌
3. 校验对比度，不合格就加深文字
4. 输出到 CSS 与元数据

## 为什么要生成

- 手调一百套无法维护
- 生成能保证结构一致、对比度达标
- 新增主题只需加一行种子

## 精度说明

生成的主题是**近似取色**，不代表任何官方品牌规范。要精确色值请以官方为准。

## 怎么改

- 改单个主题：编辑种子列表里对应那一行
- 改规则：编辑生成脚本里的算法
- 重新生成：运行生成命令

## 小结

一百套的意义不是数量多，而是**换主题不会破坏结构**——因为所有主题共用同一套令牌定义。
