# 代码块：语言标记、行内代码与高亮

技术写作里，代码块的正确率直接决定可读性。

## 两种形态

~~~markdown
行内：使用 console.log() 输出（两侧各一个反引号）。

块级：
~~~js
const price = 12;
console.log(price);
~~~
~~~

## 为什么一定要标语言

| 写法 | 结果 |
| --- | --- |
| 只有围栏 | 纯色块，无高亮 |
| 围栏加 js | 关键字着色 |
| 围栏加 bash | 命令着色 |

支持的语言名与 highlight.js 一致：js、ts、json、bash、python、css、html、md 等。

## 代码块里要显示反引号

用四个反引号开外层，内层三个就是普通字符：

~~~text
最外层：四个反引号
内层：三个反引号加 js
再内层：三行代码
收尾：三个反引号，然后四个反引号
~~~

## 行内代码的用途

- 变量名、函数名：fetchData
- 文件名、路径：src/main.js
- 命令：npm run dev
- 快捷键：Ctrl 加 S

**不要**用它做彩色文字——语义不对，导出到公众号还可能被当成代码样式处理。

## 长代码怎么办

1. 只保留关键 10 到 20 行
2. 用注释标出省略处
3. 超长代码放仓库，正文给链接

## 复制体验

本站代码块右上角有复制按钮；导出到公众号后按钮会被去掉（平台不执行脚本），内容仍可选中复制。

## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 代码没高亮 | 没标语言 | 加语言名 |
| 代码块跑到段落里 | 前面没空行 | 加空行 |
| 代码被解析成列表 | 行首有短横线或数字 | 用围栏式代码块 |
| 缩进全乱 | 混用 Tab 与空格 | 统一 2 空格 |
