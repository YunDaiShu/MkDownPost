# Markdown 转公众号排版：一次粘贴，直接发布

公众号后台的编辑器不认 Markdown。你把 `## 标题` 粘进去，它给你原样显示两个井号；你把表格粘进去，它变成一堆竖线。这是很多人放弃用 Markdown 写公众号的原因。

但这件事故意做得笨一点就能解决：**在浏览器里把 Markdown 渲染成带内联样式的 HTML，再整段粘进后台。**

## 为什么不能直接粘 Markdown

公众号后台是富文本编辑器，它只理解 HTML 的标签和样式。Markdown 是纯文本记号，没有任何"渲染"这一步，所以粘进去当然还是文本。

有三条路可以补上这一步：

| 做法 | 代价 |
|---|---|
| 手动一段段加粗、调字号 | 一篇 3000 字的文章要 40 分钟以上 |
| 用在线排版工具 | 大多要登录、要上传内容到别人服务器 |
| 本地渲染再粘贴 | 需要工具，但内容不出本机 |

## 具体怎么做（5 步）

1. **写**：在任意 Markdown 编辑器里写完，包括标题、列表、引用、代码块、表格。
2. **渲染**：把 Markdown 转成 HTML，并且**样式必须内联**（写进每个标签的 `style` 属性），因为公众号会丢掉 `<style>` 标签和外部 CSS。
3. **选主题**：字号、行距、段间距、代码块配色。这部分决定"看起来像不像认真排过"。
4. **复制**：复制渲染结果的富文本（不是源码）。
5. **粘贴**：在公众号后台正文区 Ctrl+V，样式会跟着过来。

## 四个最容易翻车的地方

### 代码块

公众号没有代码高亮。要么用等宽字体 + 浅底色的内联样式（推荐），要么截图。截图的问题是不能改、不能被搜索、在深色模式下糊。

### 表格

公众号编辑器会吞掉 `<table>` 的部分样式，必须把 `border-collapse`、边框色、单元格内边距全部内联，否则粘进去是一堆没有边框的文字。

### 公式

KaTeX 渲染出的 HTML 依赖外部字体与 CSS，粘进公众号会散架。稳妥做法是**渲染成图片再插入**，或者在正文里用文字描述公式。

### 图片

公众号有防盗链：你在正文里放外链图片，读者端可能显示不出来。**图片必须在本地上传进公众号素材库**，粘贴前先替换。

## 复制前自测清单

- 标题层级从 h2 开始（公众号正文里 h1 会跟文章标题打架）
- 每段不超过 5 行（手机宽度）
- 代码块每行不超过 32 个字符（否则横向溢出）
- 表格列数不超过 4（再多手机上会挤）
- 所有图片都是公众号图床的地址
- 全角标点、中英文之间有空格
