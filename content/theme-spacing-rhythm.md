# 间距节奏：让页面呼吸一致

间距不统一，页面就会显得乱，但很难说出哪里乱。

## 本站的间距刻度

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| sp-1 | 4 像素 | 图标与文字之间 |
| sp-2 | 8 像素 | 紧凑元素之间 |
| sp-3 | 12 像素 | 组件内边距 |
| sp-4 | 16 像素 | 卡片内边距 |
| sp-5 | 24 像素 | 区块之间 |
| sp-6 | 32 像素 | 大区块之间 |

## 规则

1. **只用刻度上的值**，不要写 13、17 这种数字
2. **同一层级用同一个值**：所有卡片内边距都用 sp-4
3. **块间距大于行间距**：否则分不清段落与区块

## 垂直节奏

~~~text
标题
  间隔 8
副标题
  间隔 24
段落（行高 1.8）
  间隔 16
下一个标题
~~~

## 常见问题

| 现象 | 原因 |
| --- | --- |
| 页面挤 | 块间距等于行间距 |
| 页面散 | 块间距是行间距的三倍以上 |
| 卡片高低不一 | 内边距不一致 |

## 小结

间距是隐形的排版。用固定刻度、保持层级一致，页面自然稳。
