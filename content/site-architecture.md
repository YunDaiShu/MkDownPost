# 本站结构：零构建静态站是怎么组织的

没有打包器，没有后端，只有 HTML、CSS 与 ES 模块。

## 目录

~~~text
index.html        单页外壳
src/              42 个模块（路由、页面、编辑器、渲染管线、适配器）
assets/styles/    10 个样式表，构建时合并成一个
content/          81 篇文章的 Markdown 源
data/             100 套主题的元数据
tools/            零依赖脚本（本地服务、截图、审计、生成）
vendor/           第三方库，全部本地
~~~

## 一次访问发生了什么

1. 浏览器加载 index.html（只有一个 CSS）
2. 加载入口模块 main.js
3. 路由按 hash 决定渲染哪个页面
4. 页面模块按需 import 依赖（渲染器、适配器）

## 为什么不做构建

- 改一行就能刷新看到结果
- 没有 node_modules，没有版本漂移
- 直接在 GitHub Pages 上跑

代价是：需要自己管好模块导入与缓存版本号。

## 小结

零构建不是"没有工程"，而是**把复杂度换成了纪律**：模块边界清楚、依赖按需加载。
