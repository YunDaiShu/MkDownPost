# 导出内联样式 HTML：粘贴即用的关键

这是本站最重要的导出，没有之一。

## 它解决什么问题

公众号编辑器会过滤样式表与 class，只保留写在元素上的行内样式。所以导出器做了三件事：

1. 读取当前主题的 23 个令牌
2. 把每条规则计算成行内样式
3. 移除脚本类交互（复制按钮、锚点）

## 使用步骤

1. 点导出里的"导出内联样式 HTML"
2. 打开下载的文件，全选复制
3. 粘贴到公众号或其他富文本编辑器

## 产物包含什么

| 内容 | 是否包含 |
| --- | --- |
| 标题、段落、列表 | 是 |
| 表格（含表头底色） | 是 |
| 代码块（底色与等宽字体） | 是 |
| 引用（竖条与浅底） | 是 |
| 复制按钮 | 否，导出时移除 |
| 外链样式表 | 否，全部内联 |

## 常见问题

- **粘进去样式全丢**：复制的是预览而不是导出文件
- **代码块变灰块**：平台重写了底色，可接受
- **表格挤**：列太多，改列表

## 小结

要发到任何富文本平台，认准"内联样式 HTML"这一条路。
