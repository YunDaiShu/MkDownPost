# 数学公式：行内、块级与 KaTeX 渲染

公式在技术文里很常见，但它也是最容易"在 A 平台好看、在 B 平台乱码"的内容。

## 两种写法

```markdown
行内公式：质量为 $m$，速度为 $v$。

块级公式：

$$
E = mc^2
$$
```

## 常见符号速查

| 想写 | 写法 |
| --- | --- |
| 上下标 | a^2, x_i |
| 分数 | 反斜杠 frac 加花括号 |
| 求和 | 反斜杠 sum 加下标 |
| 积分 | 反斜杠 int 加上下限 |
| 希腊字母 | 反斜杠 alpha、反斜杠 beta |

## 本站的渲染方式

- 公式由 KaTeX 在浏览器本地渲染，不请求外部服务
- 块级公式渲染失败时会保留源码，不会白屏
- 编辑器有实时公式预览提示

## 各平台支持

| 平台 | 支持 | 备注 |
| --- | --- | --- |
| 本站预览 | 支持 | KaTeX 本地渲染 |
| GitHub | 部分 | 需仓库开启数学渲染 |
| 公众号 | 不支持 | 会显示原始源码 |
| 知乎 | 不支持 | 同上 |
| 掘金 | 部分 | 视编辑器而定 |

## 公众号里怎么办

1. **改成文字描述**：把公式讲成一句话
2. **截图贴图**：最稳，但不可复制
3. **用行内代码包住**：至少看起来像公式而不是乱码

```markdown
勾股定理：直角边平方和等于斜边平方。
```

## 写作建议

- 公式只写"必要的那几个"，不要整页推导
- 每个公式配一句人话解释
- 多平台发布时，公式部分单独截图

## 小结

公式是"高价值、低兼容"的内容。自己看用 LaTeX，发出去用文字或截图。
