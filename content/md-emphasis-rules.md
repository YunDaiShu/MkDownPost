# 强调：加粗、斜体、删除线的正确用法

强调是语气，不是装饰。滥用会让重点彻底失效。

## 语法一览

```markdown
单个星号包围 → 斜体
双星号包围 → 粗体
三星号包围 → 粗斜体
双波浪线包围 → 删除线
单下划线包围 → 斜体（英文更稳）
```

## 什么时候用哪种

| 强调方式 | 语义 | 建议场景 |
| --- | --- | --- |
| 加粗 | 关键词、结论 | 每段最多 1 到 2 处 |
| 斜体 | 术语、书名、外来语 | 中文里少用，观感偏弱 |
| 删除线 | 修订痕迹 | 只在变更说明里用 |

## 中文环境的坑

```markdown
这是**加粗**正常。
这段**紧贴标点**，可能失效。
```

- 星号内侧紧贴标点时，部分解析器不认
- 最稳的写法：星号两侧各留普通字符或空格
- 行内代码里的星号不会被解析

## 下划线还是星号

```markdown
请设置 my_var_name 的值。（下划线可能被当成强调）
请把变量名放进行内代码再展示。（最安全）
```

## 什么时候不要强调

- **整段加粗**：等于没有重点
- **标题里加粗**：标题本身就是强调
- **连续三处以上**：读者会放弃抓重点
- **给按钮文字加斜体**：降低可读性

## 一份克制的写法

```markdown
核心结论：**先做完，再做好**。

具体做法：
- 一次只写一节
- 允许烂句子
- 写完统一打磨
```

## 小结

强调的目的是**引导视线**。每屏（约 300 字）最多两处加粗，超过就说明还没想清楚哪里最重要。
