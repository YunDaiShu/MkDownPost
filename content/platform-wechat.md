# 公众号发布：从粘贴到自检

公众号是最挑剔的平台，但也有规律。

## 发布流程

1. 编辑器里选微信主题
2. 导出内联样式 HTML
3. 全选复制
4. 公众号后台新建图文，粘贴
5. 手机预览自检

## 会被过滤的东西

| 内容 | 结果 |
| --- | --- |
| 样式表与脚本 | 移除 |
| class 与 id | 移除 |
| 行内 style | 保留大部分 |
| 外链 | 受白名单限制 |
| 锚点 | 移除 |
| 复制按钮 | 移除 |

## 排版建议

- 版心 677 像素，对应本站"标准"行宽
- 字号 16 像素最稳
- 表格不超过 3 列
- 代码块尽量短

## 粘贴后五项自检

- [ ] 标题没有并进正文
- [ ] 图片全部显示
- [ ] 表格没有横向溢出
- [ ] 代码块底色还在
- [ ] 外链可点

## 小结

公众号发布的关键是"内联加自检"。样式丢了一定是复制方式不对，不是编辑器坏了。
