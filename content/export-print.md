# 打印与另存为 PDF：两个模板

浏览器打印是"可获得可搜索 PDF"的官方路径。

## 两个模板

| 模板 | 特点 | 适用 |
| --- | --- | --- |
| 主题色 | 保留品牌色与装饰 | 内部存档、展示 |
| 极简黑白 | 去掉底色，只留结构 | 正式文档、省墨 |

## 正确用法

1. 点"打印预览"
2. 在弹出的打印窗口里选择目标打印机为"另存为 PDF"
3. 保存

## 为什么它和"导出 PDF"不同

| 项 | 导出 PDF | 打印另存 |
| --- | --- | --- |
| 文字可选中 | 否 | 是 |
| 版式 | 图片分页 | 浏览器排版 |
| 样式控制 | 完全可控 | 受打印样式影响 |
| 是否需要对话框 | 否 | 是 |

## 打印样式做了什么

- 隐藏导航、按钮、工具栏
- 保留正文、表格、代码块
- 页边距按 A4 设置
- 链接后附上地址（可选）

## 小结

要"可搜索的 PDF"，就用打印另存；要"和屏幕完全一致"，用导出 PDF。
