# 3 分钟上手：写出第一篇能直接发布的稿子

第一次来，你大概只想知道三件事：**这东西怎么用、写完怎么发、会不会很麻烦**。这篇就是回答。

## 第 1 步：打开编辑器

点顶部「编辑器」，或直接访问 `/#/editor`。

你会看到三块：

| 区域 | 作用 |
|---|---|
| 左栏 | 写 Markdown 的地方（带行号） |
| 中间细条 | 拖动可调整左右宽度 |
| 右栏 | 实时预览，也就是"发出去长什么样" |

左下角显示「已保存于 14:32」——稿子自动存在**本机浏览器**里，不用点保存。

## 第 2 步：只用 5 个语法就能写完一篇

真的只要 5 个：

```markdown
# 文章标题

一段正文。想强调就 **加粗**，想标记术语就用 `行内代码`。

## 小标题

- 要点一
- 要点二

> 需要强调的一句话放引用里。
```

渲染出来就是：标题 / 正文 / 小标题 / 列表 / 引用块。**公众号最常用的排版件，这 5 个已覆盖八成**。

## 第 3 步：挑一套主题

点右上角「主题」按钮 → 弹出「配色」面板 → 点任意一张卡片**即刻生效**（不需要点"应用"）。

- 写公众号：`wechat`
- 写小黑盒：`heybox`（近黑冷灰，和官网一致）
- 写 TapTap：`taptap`
- 想要极简：`notion` / `linear`

主题只改颜色与装饰，**不动内容结构**，随时可换。

## 第 4 步：导出

点右上角「导出 ▾」，按目标选：

| 目标 | 选哪个 |
|---|---|
| 公众号 / 知乎等富文本编辑器 | **导出内联样式 HTML** → 全选复制 → 粘贴 |
| 存档 / 交付 | **导出 PDF** 或 **导出 Word（.doc）** |
| 发图 / 群分享 | **导出 PNG 长图** |
| 只拿走源码 | 下载 .md |
| 小黑盒 / TapTap | **平台适配导出…** |

## 第 5 步：粘贴到公众号

1. 点「导出 → 内联样式 HTML」
2. 打开下载的 .html，全选（Ctrl/⌘ + A）复制
3. 粘进公众号编辑器 → 样式会跟着走

> 为什么必须"内联"？公众号编辑器会过滤 `<style>` 标签，只有写在元素上的样式才留得住。

## 常用快捷键（记 4 个就够）

| 快捷键 | 作用 |
|---|---|
| Ctrl/⌘ + B | 加粗 |
| Ctrl/⌘ + K | 插入链接 |
| Ctrl/⌘ + S | 手动保存草稿 |
| ? | 打开全部快捷键（可自定义） |

## 新手最容易踩的三个点

1. **看不到高亮？** 语法高亮默认关闭（避免双层重影），工具栏铅笔图标可开。
2. **长行不换行？** 编辑器是横向滚动（与代码编辑器一致），保证输入层与着色层严格对齐。想看折行看右侧预览。
3. **PDF 里字选不中？** 当前 PDF 是图片型（视觉一致）。要可搜索：导出 HTML → 浏览器打印 → 另存为 PDF。
