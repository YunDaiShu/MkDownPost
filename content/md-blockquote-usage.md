# 引用块：不只是摘抄

引用块在技术写作里有三种更实用的用法。

## 基础语法

```markdown
> 单行引用

> 多段引用
>
> 空行也要带引用符号

>> 嵌套引用
```

## 三种实用场景

### 一、放注意事项

```markdown
> 注意：公众号会过滤 style 标签，样式必须内联。
```

### 二、放原文摘录

```markdown
> 引用自某规范：
> 空行是块级元素的分隔符。
```

### 三、放结论

```markdown
> 一句话结论：内容与排版分离，才能一次写多处发。
```

## 引用块里的其他元素

| 可以放 | 写法 | 注意 |
| --- | --- | --- |
| 列表 | 引用符号加短横线 | 每行都要带引用符号 |
| 代码 | 引用符号加围栏 | 两层缩进容易乱 |
| 标题 | 引用符号加井号 | 部分平台不解析 |

## 各平台表现

- **公众号**：左侧竖条加浅底（本站导出会内联这两种样式）
- **小黑盒**：竖条显示，浅底常被去掉
- **TapTap**：可能退化为普通缩进段落
- **GitHub**：标准左竖条

## 别这样用

- **整篇包在引用里**：观感像引文，失去重点作用
- **用引用代替小标题**：目录里不会出现
- **引用里嵌三层**：手机上几乎无法阅读

## 小结

引用块是语气容器：把提醒、原文、结论从正文里拎出来。每篇一到三处最合适。
