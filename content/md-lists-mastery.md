# 列表：无序、有序、嵌套与任务列表

列表是长文里最提效的结构，前提是别写错。

## 三种列表

```markdown
- 无序项
+ 也可以用加号
* 也可以用星号（同一列表保持一致）

1. 有序项
1. 自动编号

- [x] 已完成
- [ ] 未完成
```

## 嵌套规则

```markdown
- 第一层
  - 第二层（缩进 2 空格）
    - 第三层（缩进 4 空格）
```

- 缩进用 2 或 4 个空格，不要混用 Tab 与空格
- 嵌套超过 3 层，手机上会挤成一团

## 有序列表的编号

```markdown
1. 第一步
1. 第二步（写 1 也会自动编号为 2）
5. 第三步（写 5 也可能被改成 3）
```

编号由解析器接管，手写的数字**不保证被采用**。

## 列表里放代码块

```markdown
1. 安装依赖：

       npm install

2. 启动服务：

       npm run dev
```

代码块要相对列表再缩进 4 空格，否则会被并进文字。

## 列表里放引用与表格

```markdown
- 引用示例：

  > 这一段是列表里的引用

- 表格示例：

  | a | b |
  | --- | --- |
  | 1 | 2 |
```

## 常见错误

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 列表没生效 | 前面没有空行 | 加空行 |
| 列表变成一行 | 项之间没换行 | 每项独立一行 |
| 编号乱跳 | 手写数字又混用 | 全写 1. 让工具编号 |
| 任务列表没方框 | 平台不支持 GFM | 改用勾选字符 |

## 选择建议

- **三条以内并列**：直接用句子，不必列表
- **步骤类**：有序列表
- **清单类**：无序列表
- **待办类**：任务列表，导出时自动降级
