# 导出后为什么看着不一样：六类差异来源

同一篇稿子，屏幕上是 A，粘到公众号变成 B。原因有六类。

## 六类差异

| 差异 | 具体表现 | 原因 |
| --- | --- | --- |
| 字体 | 变成平台默认字体 | 平台只认系统字体 |
| 间距 | 段间距变小 | 平台重写外边距 |
| 颜色 | 主色变淡 | 平台过滤部分色值 |
| 圆角 | 消失 | 平台不支持圆角 |
| 图片 | 变宽或变小 | 平台按容器重算宽度 |
| 代码块 | 顶部条消失 | 平台不执行脚本 |

## 本站的对策

- **全内联样式**：把计算后的样式写到元素上
- **去脚本**：复制按钮这类交互在导出时移除
- **限宽**：正文最大宽度按公众号版心计算
- **降级**：表格与任务列表在弱支持平台上自动改写

## 自查方法

1. 导出 HTML 后在浏览器打开，看是否与编辑器一致
2. 粘贴到平台后，用手机预览逐项对比
3. 重点看图片、表格、代码块、外链

## 小结

不一致是平台特性，不是 bug。把差异清单记住，发布前逐项确认即可。
