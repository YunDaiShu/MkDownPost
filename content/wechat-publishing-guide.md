# 公众号排版实战：从草稿到发布

这是一份操作手册，按顺序做完就能发。

## 一、先决定三件事

| 决定 | 选项 | 建议 |
|---|---|---|
| 主题 | 100 套里选 1 | 公众号首选 `wechat`；想稳重选 `zhihu` / `notion` |
| 字号 | 小 15 / 中 16 / 大 18 | 手机阅读选**中**，长文选大 |
| 行宽 | 标准 680 / 宽 820 | 公众号正文版心约 677px，选**标准** |

## 二、正文结构怎么排

读者的耐心很短，结构比文采重要：

1. **开头 3 行内说清"这篇讲什么、对你有什么用"**
2. **每 300~500 字一个小标题**，给读者"可以停一下"的锚点
3. **列表优先于长段**：3 条以上并列信息就用短横线
4. **重点用加粗，不要整段加粗**
5. **结尾给下一步动作**（关注 / 收藏 / 实践清单）

## 三、图片处理（最容易翻车）

```markdown
![封面：一句话说明这张图是什么](https://example.com/cover.jpg)
```

要点：

- 用**绝对 URL**，公众号不支持相对路径
- 首图建议 **16:9**（约 900×500），信息流裁切更完整
- 一定要写 alt：既是无障碍，也是图裂时的兜底文字
- 公众号会把图片**转存到自己的 CDN**，粘贴后逐张确认

## 四、代码块与表格

```js
const price = 12;
console.log('代码块会变成等宽 + 浅底，语言标签会被去掉');
```

- 表格建议**不超过 3 列**，多了手机上会挤
- 合并单元格请改成"列表 + 说明"，不要硬塞表格

## 五、导出与粘贴（关键 4 步）

1. 「导出 ▾」→ **导出内联样式 HTML**
2. 打开下载的 .html，Ctrl/⌘ + A 全选，Ctrl/⌘ + C 复制
3. 公众号后台 → 新建图文 → 正文区 Ctrl/⌘ + V 粘贴
4. 逐项检查：标题层级、图片、表格、代码块、外链

## 六、粘贴后的 5 项自检

- [ ] 标题没有变成正文
- [ ] 图片全部显示，没有裂图
- [ ] 表格没有横向溢出
- [ ] 代码块底纹还在
- [ ] 外链可点（公众号外链有白名单限制）

## 七、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 样式全丢 | 复制的是预览而非导出 HTML | 走「导出内联样式 HTML」 |
| 图片裂了 | 相对路径 / 防盗链 | 换绝对 URL 或先上图床 |
| 表格挤成一团 | 列太多 | 减到 3 列内或改列表 |
| 代码块没底纹 | 编辑器二次处理 | 粘贴后手动加引用样式 |
| 字号忽大忽小 | 混用标题与加粗 | 统一用 ## 与加粗 |

## 八、发布前最后一遍

1. **在手机上预览**（后台"预览"发给自己）
2. 检查首图在信息流里的裁切
3. 检查摘要（前 54 字最关键）
4. 检查是否残留草稿标记、TODO

## 九、一篇稿子的节奏建议

```text
写正文 30 分钟 → 加小标题与列表 10 分钟 → 配图 15 分钟
→ 选主题 1 分钟 → 导出粘贴 5 分钟 → 手机自检 10 分钟
```

写完不要立刻发，隔两小时再读一遍，你会删掉 20% 的废话。
