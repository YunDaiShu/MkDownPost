# 系列文章：把一个主题拆成可持续的产量

单篇爆款靠运气，系列靠结构。

## 拆分方式

| 拆法 | 适合 |
| --- | --- |
| 按难度 | 入门、进阶、原理 |
| 按场景 | 公众号、小黑盒、TapTap |
| 按问题 | 语法、排版、导出、平台 |
| 按角色 | 作者、编辑、开发者 |

## 系列的三条约束

1. **每篇能独立读懂**（不要"见上篇"）
2. **篇与篇之间有链接**（但链接不能是唯一线索）
3. **统一命名**（标题前缀一致，便于检索）

## 本站的系列示例

```text
Markdown 是什么 → 语法全解 → 生态与标准 → 边界案例
写作工作流 → 公众号实战 → 平台差异 → 发布自检
```

## 排期建议

- 一周一篇，连续四周
- 每篇 1500 到 2500 字
- 提前定好四篇标题，避免中途改方向

## 小结

系列的价值是**复利**：读者读完一篇会去找下一篇，检索也会互相带流量。
