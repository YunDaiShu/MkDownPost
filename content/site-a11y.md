# 无障碍：让键盘与读屏也能用

无障碍不是额外功能，是基本质量。

## 本站做的六件事

| 项 | 做法 |
| --- | --- |
| 语义标签 | 用 button、nav、main，而不是一堆 div |
| 焦点可见 | 统一焦点环，键盘 Tab 能看清位置 |
| 对比度 | 生成主题时校验 4.5 比 1 |
| 替代文本 | 图片支持 alt，图标按钮有 aria-label |
| 动效 | 尊重系统的减少动效设置 |
| 跳转链接 | 提供"跳到主内容" |

## 键盘可达性检查

1. 只用 Tab 键能否走完整个导航
2. 焦点环是否始终可见
3. 弹层能否用 Esc 关闭
4. 输入框是否都有可见标签

## 常见问题

| 问题 | 影响 |
| --- | --- |
| div 当按钮用 | 键盘无法触发 |
| 只有图标没有标签 | 读屏念不出功能 |
| 低对比文字 | 弱视用户看不清 |
| 动画无开关 | 前庭敏感用户不适 |

## 小结

无障碍的收益是通用的：键盘用户、移动端用户、弱视用户都会受益。
