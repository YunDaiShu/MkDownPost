# 小黑盒发布：标题层级与图片规则

小黑盒偏社区风格，排版要"轻"。

## 特点

| 项 | 表现 |
| --- | --- |
| 标题层级 | 深层标题显示弱，h4 以上建议降级 |
| 图片 | 卡片式展示，比例影响裁切 |
| 代码块 | 支持，但底色可能丢失 |
| 表格 | 支持较弱 |

## 建议做法

1. 主题选近黑冷灰（与平台观感一致）
2. 标题最多用到 h3
3. 首图用 16 比 9
4. 表格改列表

## 适配器的处理

本站平台适配导出会：

- 把 h4 及以下标题降级为加粗段落
- 把表格转成等宽文本或列表
- 保留图片与引用

## 发布自检

- [ ] 首图在信息流里没被裁掉关键内容
- [ ] 没有深层标题
- [ ] 表格已改成列表
- [ ] 图片能正常显示

## 小结

小黑盒是"读图为主"的平台。文字结构简化、图片优先，观感就对了。
