# 归档系统：三个月后还能找到

写得多不如找得到。归档系统的核心是命名与索引。

## 命名规则

~~~text
yyyy-mm-主题-关键词.md
2026-10-markdown-表格语法.md
~~~

三条约束：**可排序、可搜索、无空格**。

## 目录结构

~~~text
content/
  markdown-基础/
  markdown-进阶/
  平台适配/
  写作方法/
~~~

## 索引文件

用一个索引文件登记元信息：

| 字段 | 作用 |
| --- | --- |
| slug | 文件名与链接 |
| title | 显示标题 |
| tags | 分类与检索 |
| featured | 是否进精选 |
| readingTime | 预估阅读时长 |

## 三个月后还能找到的三个条件

1. 文件名带关键词（不要叫"未命名 3"）
2. 索引里有标签（能按主题筛）
3. 正文开头有一句摘要（检索时能判断）

## 小结

归档不是收纳，是**为未来的自己留路标**。
