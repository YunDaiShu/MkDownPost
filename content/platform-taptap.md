# TapTap 发布：容器窄，结构要降级

TapTap 的阅读容器比公众号更窄，同样的内容更容易溢出。

## 主要限制

| 项 | 表现 |
| --- | --- |
| 表格 | 支持不稳定，容易横向溢出 |
| 任务列表 | 方框显示不出 |
| 代码块 | 宽度受限 |
| 图片 | 建议不超过 640 像素宽 |

## 适配器做了什么

- 表格转成等宽文本块
- 任务列表转成勾选字符
- 代码块限宽并允许横向滚动

## 写作建议

- 单图宽度控制在 640 以内
- 避免"图片加表格"混排
- 长截图切段，每段配一句说明
- 标题不超过三级

## 发布自检

- [ ] 没有横向溢出的表格
- [ ] 图片没有被压缩得看不清
- [ ] 代码块没有超长行
- [ ] 手机端滚动顺畅

## 小结

TapTap 的原则是"降级优先"：结构越简单，显示越稳。
