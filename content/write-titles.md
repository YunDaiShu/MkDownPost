# 标题写法：让人在两秒内决定点开

标题决定打开率，副标题决定读完率。

## 四种有效结构

| 结构 | 例子 |
| --- | --- |
| 问题加解法 | 排版总乱？三个空行规则能解决八成 |
| 数字加范围 | 12 个 Markdown 边界案例 |
| 对比加结论 | 公众号和小黑盒的排版差异，一次说清 |
| 场景加收益 | 用一份稿子发四个平台的工作流 |

## 三个不要

- **不要标题党**：内容对不上，读者一次就走
- **不要抽象名词**：赋能、抓手、闭环，读者无感
- **不要超过 25 字**：手机上一行显示不全

## 副标题的作用

```text
主标题：说清"讲什么"
副标题：说清"对谁有用、能带走什么"
```

## 自检三问

1. 只看标题，能猜出文章讲什么吗
2. 标题里有具体对象吗（公众号、代码块、表格）
3. 有没有可删的形容词

## 小结

好标题不是写出来的，是改出来的。写完文章再回头改标题，通常能砍掉一半废话。
