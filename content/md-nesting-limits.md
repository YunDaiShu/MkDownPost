# 嵌套的边界：多深算过深

嵌套能表达层级，但手机屏幕只有 375 像素宽。

## 常见嵌套

```markdown
- 一级
  - 二级
    - 三级
      - 四级
```

## 手机端的实际表现

| 层级 | 剩余宽度 | 观感 |
| --- | --- | --- |
| 1 到 2 层 | 充足 | 正常 |
| 3 层 | 偏窄 | 尚可 |
| 4 层 | 很窄 | 挤 |
| 5 层以上 | 不可读 | 禁止 |

## 更该用的结构

| 想要 | 别用 | 改用 |
| --- | --- | --- |
| 三层以上的层级 | 深嵌套列表 | 小标题分段 |
| 分类加子项 | 嵌套列表 | 表格 |
| 步骤里的子步骤 | 嵌套有序列表 | 编号加字母 |

```markdown
### 第一步：准备

1. 安装依赖
2. 配置环境

### 第二步：启动
```

## 引用与列表混嵌

```markdown
> 引用外层
>
> - 里面的列表
>   > 列表里的引用
```

两层已经足够表达"引用中的清单"，第三层就别加了。

## 小结

嵌套超过三层，说明结构该拆了——用 h3 分段比缩进更清楚。
