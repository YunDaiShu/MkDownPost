# 导出 PNG 长图：一张图发完一篇文章

长图适合群分享、社交平台预览、快速归档。

## 本站的做法

1. 把内容克隆到离屏容器
2. 固定版心宽度，让内容完整展开
3. 用渲染库截图，输出 2 倍清晰度的 PNG

## 关键点：为什么克隆

预览窗有最大宽度和滚动条，直接截图只会截到可视区域，右侧会被裁掉。所以必须先克隆、展开、再截。

## 长图的三个注意

| 项 | 建议 |
| --- | --- |
| 高度 | 超过 8000 像素时部分应用会压缩 |
| 宽度 | 700 到 800 像素最通用 |
| 内容 | 去掉导航与按钮，只留正文 |

## 使用场景

- 微信群里发一篇完整文章
- 作为社交平台的图片版
- 归档时保留"当时的样子"

## 小结

PNG 是"视觉快照"。要文字可复制，用 HTML 或 Markdown，不要用图片。
