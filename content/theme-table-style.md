# 表格样式：表头、斑马纹与限宽

表格样式做不好，数据会变成一片灰。

## 本站的处理

| 部分 | 样式 |
| --- | --- |
| 表头 | 浅底加粗体 |
| 单元格 | 上下细线，左右无线 |
| 悬停 | 行背景轻微变化 |
| 超宽 | 外层横向滚动 |

## 为什么不要竖线

竖线会让表格看起来像铁丝网。现代排版多用只有横线或只有表头底色两种做法。

## 斑马纹要不要

| 行数 | 建议 |
| --- | --- |
| 少于 6 行 | 不需要 |
| 6 到 15 行 | 可以加 |
| 超过 15 行 | 建议拆表或改列表 |

## 列宽怎么分配

Markdown 不能指定列宽，但可以控制内容长度：

- **短列**：状态、编号
- **长列**：说明、备注，放在最后一列
- **避免**：一列很长一列很短

## 导出注意

- 公众号：内联后基本可用，但列多会挤
- 小黑盒与 TapTap：会降级，建议改列表
- PDF 与 PNG：与屏幕一致

## 小结

表格样式越轻越好：表头有底色、单元格只有横线、超宽就滚动。
