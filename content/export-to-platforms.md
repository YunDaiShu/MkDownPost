# 三个平台的导出差异

## 公众号：全内联样式

公众号编辑器会过滤掉 `<style>` 标签，所以必须把样式写到每个元素上。

我们把主题色、字号、行高、表格边框全部内联，粘贴后不掉样式。

## 小黑盒：结构与图片

- 4–6 级标题显示弱 → 降级为加粗文本
- 链接加 `target="_blank"`
- 图片限制最大宽度，避免撑破卡片

## TapTap：兼容降级

| 元素 | 处理 |
| --- | --- |
| 任务列表 | 降级为 ☑ / ☐ 文本 |
| 表格 | 转为等宽文本块 |
| 代码块 | 保留 `pre` |

## 导出前检查清单

- [ ] 主题选好了吗（切换主题后需重新导出）
- [ ] 图片链接可公开访问吗
- [ ] 表格在目标平台是否需要降级
- [ ] 首图是否 16:9
