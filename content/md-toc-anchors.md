# 目录与锚点：让长文可跳读

一篇 3000 字的文章，没有目录等于劝退。

## 目录怎么来的

本站文章的右侧目录由 h2 与 h3 **自动生成**，不需要手写。

## 锚点的规则

- 每个标题会自动获得一个 id
- 中文标题的 id 通常由标题文本生成
- 同名标题会产生重复 id，导致跳转错位

```markdown
## 常见问题
## 常见问题     ← 第二个会跳到第一个
```

## 手写锚点（可选）

```markdown
<a name="top"></a>
回到顶部：<a href="#top">顶部</a>
```

注意：公众号会过滤锚点，导出的 HTML 里会被移除。

## 目录长度的建议

| 标题数 | 观感 |
| --- | --- |
| 3 到 6 个 | 清爽，适合短文 |
| 7 到 12 个 | 标准长文 |
| 超过 15 个 | 目录比正文还长，考虑合并章节 |

## 标题命名的三个技巧

1. **带动词**：怎么写、为什么错、如何验证
2. **带数字**：5 个坑、3 步走完
3. **保持一致粒度**：都是"动作"，或都是"问题"

## 小结

目录不是装饰，是导航。写完看目录：如果读者只看目录就能决定"读哪段"，它就合格了。
