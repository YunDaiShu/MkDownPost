# 从零写第一篇公众号排版

这是一篇可以直接在编辑器里改的示例。把左侧内容替换成你的稿子，右侧就是最终排版。

## 为什么用 Markdown 写公众号

公众号编辑器里调整格式是体力活：字号、行高、引用、代码块，每段都要手点。

用 Markdown 写，**结构一次写对，排版交给主题**。

## 三步流程

1. 在编辑器里写 Markdown
2. 选一套主题（顶部主题按钮 → 色板）
3. 导出 → 粘贴进公众号编辑器

> 小提示：导出的 HTML 是全内联样式，不依赖外部 CSS，粘贴后不会掉样式。

## 常见排版件对照

| Markdown 写法 | 渲染结果 |
| --- | --- |
| `**加粗**` | **加粗** |
| `> 引用` | 引用块（左侧竖条） |
| ```js 代码块 ``` | 带语言标签与复制按钮 |

## 一个代码块示例

```js
const theme = 'wechat';
document.documentElement.setAttribute('data-theme', theme);
```
