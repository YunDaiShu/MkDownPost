# 主题系统：一键换色

## 两层结构

1. **令牌层**（`:root`）：语义化变量，全站唯一颜色来源
2. **主题层**（`[data-theme="xxx"]`）：只覆盖颜色变量，不动布局

```css
[data-theme="wechat"]:not([data-mode="dark"]) {
  --c-primary: #07C160;
  --c-primary-text: #06803F;
  --c-link: #06803F;
}
```

## 为什么要有 --c-primary-text

品牌色直接当文字色，对比度往往不够：

- 微信绿 `#07C160` 在白色背景上只有 **2.4:1**
- 压暗到 `#06803F` 后是 **4.9:1**，达到 WCAG AA

所以：`--c-primary` 用于背景与描边，`--c-primary-text` 用于标题与链接。

## 对比度自检

| 主题 | 正文 | 标题 |
| --- | --- | --- |
| deepseek | 16.8:1 | 4.9:1 |
| bilibili | 16.8:1 | 4.7:1 |
| github | 16.8:1 | 5.1:1 |

## 复制变量

主题面板右下角「复制当前主题 CSS 变量」，直接粘到别的工具里即可复用同一套配色。
