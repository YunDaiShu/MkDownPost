# 引用样式：左侧竖条与浅底的分工

引用块的样式决定了提醒能不能被一眼识别。

## 本站的两层视觉

| 元素 | 作用 |
| --- | --- |
| 左侧竖条 | 结构标识：这里是引用 |
| 浅色底 | 视觉降噪：与正文区分 |

两者都走主题令牌：竖条用主色，底色用主色浅底。

## 不同主题分组的差异

| 分组 | 引用样式 |
| --- | --- |
| dev | 细竖条加深灰底 |
| social | 圆角浅底，无竖条 |
| game | 双竖条，左右各一条 |
| system | 大圆角灰底 |
| cn | 竖条加引号符号 |

## 什么时候需要重样式

- 引用很短（一句结论）：竖条就够
- 引用较长：加底色更清楚
- 引用是警告：可以局部加语义色

## 别这样做

- **整段用引用**：失去强调作用
- **引用里再嵌三层**：手机上糊成一团
- **用引用模拟代码块**：导出后会变形

## 小结

引用样式的最小可用集是一根竖条。要加底色，就用主色的极浅版本，别用灰色，否则显脏。
