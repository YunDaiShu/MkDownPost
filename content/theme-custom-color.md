# 自定义主色：换一个颜色，全站跟着变

不想用 100 套里的任何一套？只改主色就够了。

## 怎么改

1. 点右上角主题按钮，打开配色面板
2. 找到颜色输入框，选一个颜色
3. 全站立刻应用，并写入本地偏好

## 背后发生了什么

系统会用你选的色算出 23 个令牌：

| 计算项 | 规则 |
| --- | --- |
| primary | 你选的色 |
| primary-text | 若对比度不足则自动加深 |
| primary-soft | 混合白，用于浅底 |
| primary-bg | 更淡，用于卡片底 |
| focus-ring | 取主色，保证可见 |

## 选色建议

- **避免纯黄**：白底上几乎不可读
- **避免纯黑**：和正文撞色，分不清主次
- **中等饱和最稳**：太灰没精神，太艳刺眼

## 对比度自检

正文与背景的对比度应不低于 4.5 比 1。本站生成主题时会自动校验，低于阈值会加深文字色。

## 导出会跟着变吗

会。导出的 HTML、PDF、PNG 都是当前视觉，包括你自定义的主色。

## 小结

自定义主色是性价比最高的定制：一次改动，全站联动，不用改任何 CSS。
