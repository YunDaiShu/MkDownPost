# 灵感收集：写不出来时该做什么

写作卡住，往往不是能力问题，是**输入断了**。

## 一个最小的收集系统

~~~text
inbox.md
- 今天看到的一个排版问题
- 某个平台的新规则
- 读者问的一个问题
~~~

一条一行，不排版、不分类。每周清一次。

## 三条判断标准

| 标准 | 说明 |
| --- | --- |
| 我能写出 800 字吗 | 不能就合并到别的选题 |
| 有人会搜这个吗 | 会，就值得写 |
| 我有一手经验吗 | 有，就优先写 |

## 从问题里找选题

读者的提问是最好的选题来源，因为**已经证明有人需要**。

## 输入来源

- 平台规则变更
- 自己踩的坑
- 别人踩的坑（论坛、issue）
- 工具更新日志

## 小结

写作是输出，收集是输入。每天存三条，一个月就有九个选题。
