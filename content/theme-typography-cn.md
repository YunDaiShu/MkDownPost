# 中文排版：字号、行高与字距

中文和英文的排版规则不同，直接套西文参数会显得挤或散。

## 本站的取值

| 项 | 值 | 理由 |
| --- | --- | --- |
| 正文字号 | 16 像素，可切 15 与 18 | 手机阅读舒适区 |
| 行高 | 1.75 到 1.8 | 中文笔画密，需要更多行间呼吸 |
| 段间距 | 约一行 | 中文不靠首行缩进 |
| 字距 | 0 | 中文不需要额外字距 |
| 标题字重 | 600 | 明显但不生硬 |

## 中文特有的三件事

1. **标点占全角**：句号逗号后面自然有间隔，别再手动加空格
2. **中英混排**：英文与数字两侧留半角空格更清爽
3. **不要首行缩进**：现代网页排版用段间距代替

```markdown
推荐：在 Markdown 里写 3 套主题（中英文间留空格）。
不推荐：在 Markdown 里写３套主题（全角数字混排）。
```

## 行高的经验公式

正文行高约为字号 1.7 到 1.8 倍，代码块 1.6 倍，标题 1.2 到 1.3 倍。

## 常见误区

- **行高过大**：段落松散，读起来累
- **字号过小**：14 像素在手机上偏小
- **全文加粗**：相当于没有重点

## 小结

中文排版的关键不是花哨，而是行高与段间距。这两项对了，观感立刻专业。
