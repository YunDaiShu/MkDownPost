# 表格：语法、对齐与降级

表格是 Markdown 里看起来最强、实际最脆的结构。

## 基础语法

```markdown
| 平台 | 状态 | 备注 |
| --- | :---: | ---: |
| 公众号 | 稳定 | 全内联 |
| 小黑盒 | 稳定 | 图文 |
```

第二行的冒号控制对齐：左、中、右。

## 三条硬限制

1. **不能合并单元格**（要合并就退回 HTML 或改列表）
2. **单元格内不能换行**
3. **列宽不能指定**，由内容撑开

## 竖线要转义

```markdown
| 表达式 | 说明 |
| --- | --- |
| 竖线写作反斜杠加竖线 | 单元格里的竖线必须转义 |
```

不转义会把一格拆成两格。

## 各平台支持情况

| 平台 | 支持 | 表现 |
| --- | --- | --- |
| 公众号 | 部分 | 内联样式后基本可用，列多会挤 |
| 小黑盒 | 弱 | 建议改列表 |
| TapTap | 弱 | 自动降级为等宽文本 |
| 知乎 | 一般 | 需限宽 |
| GitHub | 完整 | 原生 GFM |

## 什么时候别用表格

- **超过 4 列**：手机上必须横向滚动
- **内容长度差异大**：一列很长会撑爆布局
- **需要合并单元格**：改列表加说明更清楚

## 表格的替代写法

```markdown
**公众号**
- 状态：稳定
- 备注：全内联样式

**小黑盒**
- 状态：稳定
- 备注：图文规则
```

信息量一样，但手机端更友好。

## 小结

表格适合短词条的横向对比；一旦需要长句、合并、嵌套，就换成列表或小标题分段。
