# 分隔线与转义：小符号，大坑

两个最容易被忽略的语法：分隔线与反斜杠。

## 分隔线

```markdown
三个短横线
三个星号
三个下划线
```

三个以上即可，但要注意：

| 写法 | 风险 |
| --- | --- |
| 紧跟在文字下方 | 会被当成二级标题 |
| 跟在空行之后 | 正常渲染为分隔线 |
| 在列表项里 | 可能被当成列表内容 |

**规则**：分隔线前后各留一个空行。

## 什么时候该用分隔线

- 文章有附录、更新日志这类明显分段
- 长文里切换话题（但小标题更好）

公众号里分隔线常被渲染成很粗的灰条，能不用就不用，用 h2 更清晰。

## 转义

```markdown
反斜杠加星号 → 不是斜体
反斜杠加井号 → 不是标题
反斜杠加竖线 → 不是表格分隔
反斜杠加方括号 → 不是链接
```

可转义字符包括反斜杠、星号、下划线、花括号、方括号、圆括号、井号、加号、短横线、点、感叹号、竖线。

## 四种常见场景

### 一、行首要写数字点号

```markdown
2024. 这一年发生了很多事。
```

不转义会被当成有序列表第 2024 项。

### 二、写通配符

```markdown
*.md 表示所有 Markdown 文件。
```

### 三、写数学乘号

```markdown
2 * 3 = 6
```

### 四、写 HTML 标签本身

```markdown
<div> 会被显示成文字
```

## 小结

分隔线慎用，转义常备。两者都属于不出问题时想不起来、出问题时到处找的语法。
