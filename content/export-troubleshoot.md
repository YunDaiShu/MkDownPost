# 导出排错：九种现象与对应原因

导出出问题，先按现象定位。

## 现象与原因

| 现象 | 大概率原因 |
| --- | --- |
| 粘进去样式全丢 | 复制的是预览而不是导出文件 |
| 图片全部裂 | 用了相对路径或图片有防盗链 |
| 表格挤成一团 | 列太多，超过 3 到 4 列 |
| 代码块没有底色 | 平台重写样式，可接受 |
| 字体变成默认 | 平台只认系统字体 |
| 公式显示源码 | 平台不解析 LaTeX |
| 图表显示不出来 | 平台不支持 Mermaid |
| PDF 里字选不中 | 图片型 PDF 的固有属性 |
| Word 里图片空白 | 图片地址不可访问或需要联网 |

## 排查顺序

1. **先看源**：.md 里是否有相对路径、超长行
2. **再看导出物**：导出的 HTML 在浏览器打开是否正常
3. **最后看平台**：粘贴后用手机预览

## 三个一劳永逸的做法

- 图片一律用 https 绝对地址
- 表格控制在 3 列内
- 代码块标语言并控制行长

## 小结

排错的顺序永远是"源、导出物、平台"。跳过前两步直接怪平台，会浪费很多时间。
