关于 MkDownPost · 码稿

MkDownPost 是一个在浏览器里把 Markdown 渲染成各平台可用排版的工具。你在左边写 Markdown，右边实时看到公众号里的样子，点一下复制，粘进后台就有样式。整个过程不上传内容、不需要账号、不联网也能用。

它解决的是一个很具体的问题：公众号后台只认富文本。你把 Markdown 粘进去，标题会变成两个井号，表格会变成一堆竖线，代码块会变成普通正文。重新手工排版一篇 3000 字的文章要花 40 分钟以上，而人一旦排过一遍，就再也不想写第二篇。

所以这里做的是把中间那一步自动化：Markdown 解析、样式内联、主题套用、一键复制。目前提供 147 套主题、8 种代码配色，覆盖公众号、小黑盒、TapTap、知乎等平台的导出格式。字号、行距、段间距三个参数可以单独调，而不是只能整套换。

常见问题

需要注册账号吗？
不需要。没有账号系统，没有登录，也没有云端同步。
我的文章会被上传吗？
不会。解析、渲染、主题套用全部在你的浏览器里完成；断网之后编辑器仍然可用，可以作为验证。
免费吗？
免费，也没有付费版本或功能限制。项目源码以 MIT 许可公开在 GitHub 上。
能直接粘进公众号后台吗？
能。复制的是富文本，在公众号正文区粘贴即可，标题、列表、引用、表格、代码块的样式都会跟过去。图片需要先上传到公众号素材库，这是公众号的防盗链限制。
支持公式和表格吗？
支持 GFM 表格与 KaTeX 公式。但公众号对公式支持有限，正式发布前建议渲染成图片。
草稿存在哪里？
存在你自己浏览器的 localStorage 里，换浏览器或清缓存会丢，请用「导出」保存成文件。
